# Campfire

A campfire made with the classic Doom fire effect, with sparks and logs.

![screenshot](screenshot.png)

## Install

Copy `wallpaper.lua` to the SD card as `/sd/wallpaper.lua`. The launcher shows it on the home screen.

## Controls (app only)

| Button | Action |
| --- | --- |
| A | Put out / light |
| START | Exit |
