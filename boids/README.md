# Boids

A flock of birds over a sunflower field at sunset. Each bird follows its neighbours without bumping into them.

![screenshot](screenshot.png)

## Install

Copy `wallpaper.lua` to the SD card as `/sd/wallpaper.lua`. The launcher shows it on the home screen.

## Controls (app only)

| Button | Action |
| --- | --- |
| START | Exit |
