# Starfield

Stars fly toward you while the field slowly swirls. The example wallpaper from [Keira](https://github.com/lilka-dev/keira/blob/main/data/wallpaper.lua), copied unchanged.

![screenshot](screenshot.png)

## Install

Copy `wallpaper.lua` to the SD card as `/sd/wallpaper.lua`. The launcher shows it on the home screen.
