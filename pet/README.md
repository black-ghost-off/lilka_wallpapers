# Pet Cat

Мурчик the cat lives on your home screen. He gets hungry and bored as real time passes and sleeps at night (23:00–7:00). Feeding or playing at night wakes him up for a while.

![screenshot](screenshot.png)

## Install

Copy `wallpaper.lua` to the SD card as `/sd/wallpaper.lua`. To feed, play with or pet him, open `/sd/wallpaper.lua` from the file manager. His state is saved in `pet.txt`.

## Controls (app only)

| Button | Action |
| --- | --- |
| A | Feed |
| B | Play |
| C | Pet (stroke) — he purrs, a bit more joy |
| START | Exit |
