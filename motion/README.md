# Motion Demo

A demoscene reel: ten animated scenes take turns every 9 seconds, with blinds and squares transitions between them.

![screenshot](screenshot.png)

## Scenes

| | |
| --- | --- |
| **Plasma**<br>![](screenshots/01_plasma.png) | **Tunnel**<br>![](screenshots/02_tunnel.png) |
| **Morph** — sphere, torus, cube, knot, helix<br>![](screenshots/03_morph.png) | **Squash & Stretch** — bouncing cube<br>![](screenshots/04_squash.png) |
| **Twister**<br>![](screenshots/05_twister.png) | **Copper & Scroll** — bars, logo, sine scroller<br>![](screenshots/06_copper.png) |
| **Easing** — six easing functions<br>![](screenshots/07_easing.png) | **Fireworks** — over a city<br>![](screenshots/08_fireworks.png) |
| **Waves** — 3D wireframe surface<br>![](screenshots/09_waves.png) | **Harmonograph**<br>![](screenshots/10_harmonograph.png) |

## Install

Copy `wallpaper.lua` to the SD card as `/sd/wallpaper.lua`. The launcher shows it on the home screen.

## Controls (app only)

| Button | Action |
| --- | --- |
| ← → | Previous / next scene |
| A | Pause scene switching |
| START | Exit |
